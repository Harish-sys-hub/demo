# NoteNest website

A responsive note-taking app landing page and front-end demo built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser, or use VS Code's Live Server extension.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Open the published URL after GitHub finishes deploying.

## Demo functionality
- Responsive mobile navigation
- Quick capture adds notes to browser local storage
- Editor title/content autosave locally
- Live word count
- Keyboard shortcut Ctrl/Cmd + K
- Demo login dialog and pricing feedback
- No backend, authentication, payment processing, cloud sync, or account system is connected.
